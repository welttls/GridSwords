# 《炼剑》 SwordForge

修仙题材 · 放置 · 进化 · 模拟 游戏（SRD v1.0 实现）

玩家扮演剑修弟子，在十日内于宗门「剑域」投放炉材、撒布庚金之气、择选剑潮，观凡铁剑意通过采气、搏杀、繁衍、剑悟不断进化，淬炼出独属于你的本命剑意，赴宗门大比，名动万剑榜。

> 当前版本：**v1.8.1**（2026-08-10）· 已部署 Vercel 线上

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 → http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览生产构建
```

> 注意：本机 Node 为 v16，请使用 Vite 4（已配置）。若使用 Node ≥ 18 可升级到 Vite 5。

## 玩法循环

1. **择剑胚**：从五行（金/木/水/火/土）中选择初始剑意倾向，五行决定天赋技能与初始属性侧重。
2. **炼剑十日（修仙计时，1 日 = 12 时辰）**：观察剑域自主演化；**随时投食**庚金之气（每日 12 团）；**以次数使用炉材**改变整个炼剑炉；每日子时剑潮降临（温养/汹涌/凶潮/静待/默许天意）。
3. **涌现机制**：荒域灵气稀薄，无干预时剑意多自生自灭、十日可能一无所获；当某道血脉在万剑相杀中悟得自采气、自分灵之道（剑意 ≥20 且世代 ≥6），便是惊喜时刻，可点击聚焦。
4. **剑成鉴定**（第 10 日天劫收束）：边界向内收缩，选出评分最高的「本命剑」（评分 = 存续×10 + 血脉相承×20 + 剑谱总和×0.5 + 本性殊异≤15），展示悟道之树、四维雷达、本性词条与剑技，并为剑命名。
5. **宗门大比**：ATB 半即时选招决斗——选择对手与剑诀（抢攻/后手反击/游斗/快剑/雷引），本命剑的五行天赋与词条剑技成为场上招式，配合水墨背景与技能专属特效。
6. **万剑榜**：本地排行榜（前 20），上榜解锁新材料，开启下一轮演化。

## 技术架构

- **语言/工具**：TypeScript（严格模式）+ Vite
- **渲染**：PixiJS 7（世界渲染与模拟逻辑完全解耦，可 headless 运行）
- **AI**：自实现极简前馈神经网络「剑心」（26-8-4），权重可突变序列化
- **模拟核心**：`src/simulation/`（World、SwordAgent、NeuralNet、Genetics、BattleResolver、**Duel、Skills**）
- **界面**：`src/ui/`（Renderer、HUD、菜单、剑潮/炉材、灵鉴 SwordDetail、鉴定、大比、榜单、图鉴）
- **数据**：`src/data/`（炉材库、剑诀、NPC、存档、排行榜、**词条库 AffixDB**）
- **持久化**：localStorage（历史名剑、解锁进度、中断续玩，含生态/行为统计序列化）

### 演化机制要点

- **属性语义（v1.6.0 起）**：锋锐=攻击力（含暴击）、坚韧=防御力、速度=蓄条/移动、感知=闪避率+视野、杀性=凶性（暴击）、策略=孤狼/合击。
- **剑谱**：锋锐/坚固/速度/感知/杀性/策略 + 五行属性，分化时按概率剑悟（高斯突变），小概率五行蜕变。
- **剑心（神经网络）**：26 输入（8 方向×庚金/剑意/墙 + 灵力/剑体），tanh 单隐藏层 8 节点，输出 4 向移动倾向。
- **本能层**：饥饿采气（全盘扫描最近庚金之气）、好战逐敌、伤重避战、策略偏好——本能是生存助力而非保证，稳定自续是**涌现**而非默认。
- **词条系统（可遗传）**：eat30 吞金(采气≥20，能耗-30%) / kill5 斩念(击破≥3，锋锐+1.5) / fight15 百炼(历经≥12战，坚固+1.5) / roam400 游历(足迹≥250，感知+2) / poison 淬毒(rare) / parasite 寄灵(rare，击杀化敌为剑子)。
- **剑意技能**：五行天赋**每行 2 技**（剑气斩/金罡体、回春术/青藤缚、瞬水步/惊涛斩、焚天爆/烈焰甲、磐石护/地脉震）+ 词条衍生 6 技，耗精元、有冷却、带特效；灵鉴「剑技」与宗门大比招式同源。
- **战斗双轨**：野外 = 移动碰撞瞬间结算（含感知闪避、反震、后手反击、尸身化食）；宗门大比 = ATB 半即时 Duel 引擎（闪避/暴击/剑诀修正/技能特效，数值×5）。
- **炉材（道具）**：以次数使用，永久改变炼剑炉（庚金生成、身法、御风、变异偏向、雷劫、陨星等）。
- **天劫**：第 10 日庚金之气停止再生，剑域壁垒向内收缩，幸存者角逐本命剑。
- **剑尘（遗蜕）**：炼成（天劫后有幸存者）即得，开局自动淬入剑胚（+0.5 四维）；失败不得。
