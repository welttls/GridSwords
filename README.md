# 《炼剑》 SwordForge

修仙题材 · 放置 · 进化 · 模拟 游戏（SRD v1.0 实现）

玩家扮演剑修弟子，在十日内于宗门「剑域」投放材料、施加天威，引导凡铁剑意通过觅食、搏杀、繁衍、突变不断进化，最终淬炼本命剑意，赴宗门大比，冲击万剑榜。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 → http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览生产构建
```

> 注意：本机 Node 为 v16，请使用 Vite 4（已配置）。若使用 Node ≥ 18 可升级到 Vite 5。

## 玩法循环

1. **择剑胚**：从五行（金/木/水/火/土）中选择初始剑意倾向。
2. **炼剑十日（修仙计时，1 日 = 12 时辰）**：观察剑域自主演化；**随时投食**庚金之气（每日限量）、**以次数使用炉材**改变整个炼剑炉的属性；每日子时剑潮降临，可择其一道或默许天意。
3. **涌现机制**：荒域灵气稀薄，无干预时剑意多自生自灭、十日可能一无所获；当某道血脉在万剑相杀中悟得自采气、自分灵之道，便是惊喜时刻。
4. **剑成鉴定**（第 10 日天劫收束）：边界向内收缩，选出评分最高的「本命剑」，展示悟道之树、四维雷达与本性词条。
5. **宗门大比**：选择对手与剑诀，本命剑在 15×15 斗剑台自动战斗。
6. **万剑榜**：本地排行榜，上榜解锁新材料，开启下一轮演化。

## 技术架构

- **语言/工具**：TypeScript（严格模式）+ Vite
- **渲染**：PixiJS 7（世界渲染与渲染逻辑完全解耦，可 headless 运行）
- **AI**：自实现极简前馈神经网络「剑心」（26-8-4），权重可突变序列化
- **模拟核心**：`src/simulation/`（World、SwordAgent、NeuralNet、Genetics、BattleResolver）
- **界面**：`src/ui/`（Renderer、HUD、菜单、剑潮/炉材、鉴定、大比、榜单、图鉴）
- **数据**：`src/data/`（炉材库、剑诀、NPC、存档、排行榜）
- **持久化**：localStorage（历史名剑、解锁进度、中断续玩）

### 演化机制要点

- **剑谱**：锋锐/坚固/速度/感知/杀性 + 五行属性，分化时按概率剑悟（高斯突变），小概率五行蜕变。
- **剑心（神经网络）**：26 输入（8 方向×庚金/剑意/墙 + 灵力/剑体），tanh 单隐藏层 8 节点，输出 4 向移动倾向。
- **本能层**：饥饿采气（全盘扫描最近庚金之气）、好战逐敌、伤重避战——本能是生存助力而非保证，稳定自续是**涌现**而非默认。
- **战斗**：伤害 = max(1, 锋锐 − 坚固×0.5)，胜者得 50% 灵力并回气，败方剑体崩解。
- **炉材（道具）**：以次数使用，永久改变炼剑炉（庚金生成叠加、身法叠加、御风、变异偏向、雷劫、陨星等）。
- **天劫**：第 10 日庚金之气停止再生，剑域壁垒向内收缩，幸存者角逐本命剑。
